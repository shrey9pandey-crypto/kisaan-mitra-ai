# kisaan-mitra-ai
Kisan Mitra AI (meaning Farmer's Friend) is an interactive web-based platform designed to bridge the gap between advanced technology and everyday farming. It provides farmers with a simple, localized tool to analyze crop diagnostics and access modern agricultural insights.
Key Features
Interactive Dashboard: A clean, responsive interface accessible on both mobile phones and laptops.

Crop Diagnostics: A mock AI diagnostic tool designed to simulate crop health analysis and provide actionable farming solutions.

Smart Backend: Powered by a lightweight Flask server built entirely in Python.

Tech Stack Used
Backend: Python, Flask, Werkzeug

Frontend: HTML5, CSS3, JavaScript

Deployment: Hosted live on the cloud
